# Тамагочи-кликер

Проект «Тамагочи» на Python с IDLE-механикой: питомец, за которым нужно
следить, кормить, лечить и укладывать спать. За действия платят монеты,
которые можно заработать кликом (работой).

Реализовано на принципах ООП: интерфейсы `AbstractClicker`, `AbstractGame`,
`AbstractTamagochi` и их наследники.

## Правила игры

У питомца четыре показателя:

- **Голод** — растёт с каждым действием. Снижается едой.
- **Усталость** — растёт от работы, снижается играми и отдыхом.
- **Энергия** — тратится на игры, восстанавливается отдыхом.
- **Здоровье (HP)** — падает, если питомец болеет. При HP = 0 — смерть.

Питомец **заболевает**, если голод или усталость достигают 90 единиц
(шанс 30% за тик). Болезнь ускоряет ухудшение и отнимает 5 HP
за каждое действие.

## Как играть

В игре доступны действия:

| Кнопка | Действие | Что происходит |
|---|---|---|
| `1` | Пойти на работу | Заработать монеты (5–15), усталость растёт |
| `2` | Купить еду | Купить еду за монеты |
| `3` | Купить лекарство | Купить лекарство за монеты |
| `4` | Покормить | Уменьшить голод, немного снизить усталость |
| `5` | Вылечить | Восстановить HP (если есть лекарство) |
| `6` | Играть | Потратить энергию, снизить усталость |
| `7` | Отдых | Восстановить энергию, сильно снизить усталость |
| `0` | Выход | Завершить игру |

## Концовки

В игре две концовки:

- **Победа** — если питомец полностью счастлив:
  HP ≥ 80, энергия ≥ 50, голод ≤ 30, усталость ≤ 30, не болеет.
- **Проигрыш** — если здоровье питомца падает до 0.
  Появляется сообщение: `Игра окончена: Питомец умер`.

## Механика усталости

- **Работа** и **время** (после каждого действия) увеличивают усталость.
- **Игра** снижает усталость на 5, но тратит 10 энергии.
- **Отдых** снижает усталость на 10 (или на 5, если питомец болеет)
  и восстанавливает энергию.
- **Кормление** немного снижает усталость (−2).

Если усталость достигает 90 — питомец рискует заболеть.
Нужно вовремя чередовать работу с играми и отдыхом.

## Установка и запуск

```bash
# 1. Клонировать репозиторий
git clone https://github.com/scholniktop-a11y/tamagochi-scholnik.git
cd tamagochi-scholnik

# 2. Создать виртуальное окружение
python -m venv .venv

# 3. Активировать (Windows / Git Bash)
source .venv/Scripts/activate
# macOS / Linux:
# source .venv/bin/activate

# 4. Установить зависимости
pip install -r requirements.txt

# 5. Запустить игру
python main.py
